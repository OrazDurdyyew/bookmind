# Как подготовить набор вопросов для проверки моделей

Набор вопросов нужен, чтобы честно измерить, какая модель правильно отвечает по книге и составляет тесты.
Для каждого языка своя папка: `ru/`, `en/`, `tm/`.

## Структура папки

```
eval/datasets/tm/
  books/                 ← сюда кладём книги (PDF, EPUB, DOCX или TXT)
    biologiya-9.pdf
    taryh-8.docx
  questions.jsonl        ← вопросы, по одному на строку
  SOURCES.md             ← откуда взяты книги (необязательно для tm)
```

## Формат questions.jsonl

Каждая строка — один вопрос в формате JSON. Пустые строки можно оставлять.

**Вопрос, ответ на который ЕСТЬ в книге:**

```json
{"id": "tm-001", "book": "biologiya-9.pdf", "question": "Fotosintez nirede bolýar?", "answerable": true, "expected": "Ýapraklaryň hloroplastlarynda", "expected_pages": ["87"]}
```

**Вопрос, ответа на который НЕТ в книге** (но он на ту же тему):

```json
{"id": "tm-021", "book": "biologiya-9.pdf", "question": "Öýjügi ilkinji kim açdy?", "answerable": false}
```

Поля:

| Поле | Что писать |
|---|---|
| `id` | Уникальный номер: `tm-001`, `tm-002`… |
| `book` | Имя файла из папки `books/`, точно как оно называется |
| `question` | Вопрос так, как его задал бы учитель |
| `answerable` | `true`, если ответ есть в книге; `false`, если нет |
| `expected` | Короткий правильный ответ (только для `answerable: true`) |
| `expected_pages` | Номера страниц, как они **напечатаны** в книге: `["87"]` или `["87", "88"]`. Для DOCX/TXT можно `[]` |

## Правила

1. **2–3 книги** на язык, лучше учебники с настоящими главами. Хотя бы одна в PDF.
2. **20–30 вопросов** на язык.
3. Примерно **каждый пятый вопрос — без ответа в книге** (`answerable: false`), но по той же теме.
   Так мы проверяем, что модель честно говорит «в книге этого нет», а не выдумывает.
4. `expected` — коротко, только суть: «В хлоропластах», а не целый абзац.
5. Вопросы разные: факты, даты, определения, «почему», «чем отличается».
   Не только такие, где ответ — одно слово.
6. **Туркменский — только латиницей.**
7. Проверьте файл командой:

   ```bash
   cargo run -p bookmind-eval -- run --candidate qwen3-4b --embedder e5-small --langs tm --dry-run
   ```

   Если всё правильно, команда напишет `OK`. Если нет — покажет, в какой строке ошибка.
