# BookMind — обучение на RTX 5060 Ti

Этот компьютер будет дообучать языковую модель для проекта BookMind (помощник, отвечающий на вопросы по книгам на туркменском). Запускать обучение и забирать результат владелец проекта будет **удалённо**, от вас нужно один раз всё настроить (≈15 минут) и потом держать компьютер включённым.

## Что понадобится

- Windows 10 или 11, учётная запись администратора;
- видеокарта NVIDIA RTX 5060 Ti, драйвер NVIDIA **572 или новее** (обновить: nvidia.com/drivers или GeForce Experience);
- **30 ГБ** свободного места на диске C;
- интернет (можно через VPN). Один раз скачается ~11 ГБ, потом — единицы мегабайт за запуск.

## Настройка (один раз)

### 1. Tailscale — закрытая сеть между двумя компьютерами

1. Скачайте и установите Tailscale: https://tailscale.com/download/windows
2. **Не входите в свой аккаунт.** Владелец проекта пришлёт вам ключ вида `tskey-auth-…`. Откройте командную строку **от имени администратора** и выполните (вставив ключ):

   ```
   "C:\Program Files\Tailscale\tailscale.exe" up --auth-key=tskey-auth-КЛЮЧ
   ```

   Компьютер подключится к сети владельца. Ключ одноразовый, никому его не пересылайте.

Если у вас включён VPN и Tailscale не подключается — напишите владельцу, какой у вас VPN.

### 2. Скрипт настройки

1. Скачайте проект архивом: https://github.com/OrazDurdyyew/bookmind/archive/refs/heads/main.zip и распакуйте. Нужна только папка `train\remote` внутри.
2. Откройте PowerShell **от имени администратора**, перейдите в папку `train\remote` и выполните:

   ```
   powershell -ExecutionPolicy Bypass -File setup.ps1
   ```

Скрипт [setup.ps1](setup.ps1):

- включает встроенный в Windows SSH-сервер (удалённая командная строка);
- разрешает вход **только по ключу владельца проекта**, пароль вашей учётной записи никому не передаётся;
- отключает сон компьютера при питании от сети, чтобы обучение не прерывалось.

Ничего не удаляет и не меняет других настроек.

### 3. Отправьте владельцу проекта

В конце скрипт выведет несколько строк — **пользователь, адрес Tailscale, видеокарта, свободное место**. Скопируйте их и отправьте владельцу.

Если у вас уже распакован пакет `bookmind-5060` (из архива `bookmind-5060-pack.zip`), напишите также, в какой он папке. Если нет — ничего делать не надо, владелец скопирует его сам.

## Дальше

- Компьютер должен быть **включён и в интернете**. Пользоваться им можно, но во время обучения видеокарта занята полностью — игры и тяжёлые программы будут тормозить или не запустятся.
- Один запуск обучения идёт **6–10 часов**. Если компьютер выключится — ничего страшного: обучение сохраняется каждые 25 шагов и продолжится с того же места.
- Всё лежит в одной папке `bookmind-5060`. Ход обучения виден в файле `bookmind-5060\out\log.txt`.
- Остановить обучение срочно: Диспетчер задач → процесс `python.exe` → «Снять задачу».

Файлы в папке `bookmind-5060` (примеры из книг) защищены авторским правом — пожалуйста, не публикуйте и не пересылайте их.

## Как закрыть доступ

В PowerShell от имени администратора:

```
powershell -ExecutionPolicy Bypass -File undo.ps1
```

[undo.ps1](undo.ps1) выключит SSH-сервер, удалит ключ владельца и отключит компьютер от сети Tailscale. Tailscale после этого можно удалить через «Установка и удаление программ», папку `bookmind-5060` — вручную.
