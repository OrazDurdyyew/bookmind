# Как составлять примеры «вопрос → ответ» по туркменским фрагментам

Вход: `train/out/batches/batch-NN.jsonl` — по одному фрагменту книги в строке
(`id`, `book`, `page_start`, `text`). Выход: `train/out/qa/batch-NN.jsonl` —
по одной строке **на каждый** входной фрагмент, в том же порядке.

## Формат строки

Годный фрагмент:

```json
{"id": "tm-0000", "question": "…?", "answer": "…", "quote": "…"}
```

Негодный фрагмент (оглавление, список, обрывки, мусор распознавания, нет ни одного факта):

```json
{"id": "tm-0001", "skip": "почему, коротко"}
```

## Правила

1. **Всё на туркменском, только туркменской латиницей**: a b ç d e ä f g h i j ž k l m n ň o ö p r s ş t u ü w y ý z.
   Никакой кириллицы, никаких турецких букв (ı, İ, ğ), никаких «ñ», «ÿ».
2. **Вопрос** — такой, какой задал бы ученик или учитель, читающий эту книгу:
   короткий, естественный, без «в этом фрагменте» и «согласно тексту».
   Разные типы: кто / что / когда / где / почему / как / что означает / перечислите.
   Не задавать вопрос, ответ на который — просто номер страницы или заголовок.
3. **Ответ** — 1–3 полных предложения, по существу, **только по тексту фрагмента**,
   без знаний со стороны. Не повторять вопрос целиком. Без ссылок [n] — их добавит скрипт.
4. **quote** — дословный кусок текста фрагмента (10–40 слов), из которого видно,
   что ответ верный. Копировать точно, символ в символ, вместе с ошибками распознавания:
   скрипт проверяет, что `quote` есть в тексте.
5. Если в тексте есть явные ошибки распознавания (например, «dyyär» вместо «diýär»),
   в **вопросе и ответе** писать правильно; в `quote` — как в тексте.
6. Не выдумывать: если по фрагменту нельзя составить вопрос с однозначным ответом — `skip`.
