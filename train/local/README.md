# Обучение туркменской модели на RTX 5060 Ti

Всё нужное — в этой папке репозитория и в интернете. Тяжёлое (Python, библиотеки, torch 2.8 ГБ, модель Qwen3-4B 8 ГБ, llama.cpp) скачивается при первом запуске, **один раз**: обрыв интернета не страшен, при повторном запуске скачивание продолжится с того же места. Если сайт не открывается, скрипт сам пробует запасные (huggingface.co → hf-mirror.com → modelscope.cn, pytorch.org → mirrors.aliyun.com).

## Перед началом

- Драйвер NVIDIA **572 или новее**.
- **40 ГБ** свободного места на диске с репозиторием.
- Путь к репозиторию **без русских букв и пробелов**, например `D:\bookmind`.
- В настройках питания Windows отключить сон (это делает и [../remote/setup.ps1](../remote/setup.ps1)).

```
git clone https://github.com/OrazDurdyyew/bookmind.git D:\bookmind
```

## Запуск

1. **`train\local\CHECK.bat`** (двойной щелчок). Сначала скачает ~11 ГБ — видно, сколько скачано и сколько осталось, — потом 5–10 минут пробует обучение. В конце должно быть «ПРОВЕРКА ПРОШЛА». Если окно закрылось или пропал интернет — просто снова `CHECK.bat`.
2. **`train\local\START.bat`** — обучение, 6–10 часов (строки «шаг N/M … осталось ~X ч»). Окно не закрывать. Если компьютер выключился — снова `START.bat`: продолжит с последнего сохранения (оно делается каждые 10 шагов, теряется не больше 20–30 минут).
3. В конце — «ГОТОВО» и файл `train\local\out\bookmind-tm-Q4_K_M.gguf`. Результат заберут удалённо; если удалённого доступа нет — заархивировать `out\lora` и `out\log.txt` (около 70 МБ) и отправить владельцу проекта.

## Новый круг обучения

```
cd D:\bookmind
git pull
```

Затем удалить папку `train\local\out` (там прошлый результат) и снова `START.bat`. Скачанное заново не качается.

При ошибке: сфотографировать экран и прислать `out\log.txt` (или `out-check\log.txt`).

## Что здесь

| файл | что делает |
|---|---|
| `get-python.bat` | ставит Python в `python\` |
| `fetch.py` | докачивает файлы из `manifest.json`, ставит библиотеки из `requirements.txt` |
| `train_5060.py` | обучение (LoRA поверх Qwen3-4B), примеры из `train\out\train.jsonl` |
| `make_gguf.py` | собирает из результата модель GGUF Q4_K_M |
| `convert\` | конвертер в GGUF из llama.cpp b11925 (MIT, см. `convert\LICENSE`) |
| `make_manifest.py` | (для владельца) обновляет `manifest.json` и `requirements.txt` |

Примеры для обучения содержат отрывки из книг с авторским правом — не публикуйте и не пересылайте их.
